Places

The places module’s root lookups: finding Google places to set as locations. Admins only.

Root fields

Section titled “Root fields”
Field Type Description
places staffql only IAudiencePlaces! The instance’s IAudiencePlaces mixin. Left out of the schema where its module isn’t installed.

Section titled “Objects”

GooglePhoto

Section titled “GooglePhoto”

Object

A photo of a place from Google, stored on our CDN. Google asks that its author be shown with it.

Field Type Description
author String Who took it, as Google credits them.
authorUrl String A link to the author’s Google Maps profile.
url PhotoURL! The photo’s CDN URL.

GooglePlace

Section titled “GooglePlace”

Object

What Google Maps says about a location, as of the last Refresh Google places run (or when its place was set). Fields Google has no value for are null.

Field Type Description
businessStatus String OPERATIONAL, CLOSED_TEMPORARILY or CLOSED_PERMANENTLY.
category String Its main type, e.g. “Gay bar” or “Night club”.
hours [String!]! Its opening hours, a line a day, e.g. “Monday: 4:00 PM – 2:00 AM”.
isOpenNow Boolean Whether it is open now by its hours; null without hours.
mapsUrl String Its page on Google Maps.
name String Its name on Google Maps.
phone String Its phone number, as written locally.
photos [GooglePhoto!]! Google’s first few photos of it.
priceLevel Int From 0 (free) to 4 (very expensive).
rating Float Its average Google review rating, from 1 to 5.
ratingCount Int How many Google reviews the rating averages.
summary String Google’s short description of it.
website String Its website, as Google lists it.

PlaceSearchResult

Section titled “PlaceSearchResult”

Object · staffql only

A place Google Maps knows, to set as a venue’s location.

Field Type Description
address staffql only String Where it is, e.g. “East Sprague Avenue, Spokane, WA, USA”.
name staffql only String Its name on Google Maps.
placeId staffql only String! Its Google place ID, for VenueInput.googlePlaceId.

PlaceSearchResultConnection

Section titled “PlaceSearchResultConnection”

Object · staffql only

The connection type for PlaceSearchResult.

Field Type Description
edges staffql only [PlaceSearchResultEdge] A list of edges.
nodes staffql only [PlaceSearchResult] A list of nodes.
pageInfo staffql only PageInfo! Information to aid in pagination.

PlaceSearchResultEdge

Section titled “PlaceSearchResultEdge”

Object · staffql only

An edge in a connection.

Field Type Description
cursor staffql only String! A cursor for use in pagination.
node staffql only PlaceSearchResult The item at the end of the edge.

PlacesProfile

Section titled “PlacesProfile”

Object · implements IPlacesProfile

The Places module’s view of a venue, locale or location.

Field Type Description
details JSON The place details stored from Google, as Google sent them. Only on a location; null on a profile.
place GooglePlace Its Google place, if its location is one.
placeId String Its Google place ID, from its location.
