Core

The audience itself and what every module builds on: users, the viewer’s state (me), tags and tribes, theme, locales and the platform’s administration.

Mutations

Section titled “Mutations”
Operation Returns Description
acceptTerms
input: TermsAcceptInput!		 TermsAcceptPayload Records that the signed-in user agreed to the terms of use, which forbid objectionable content and abuse. The apps ask before anyone chats. requires users:write:self
addAppReviewCode staffql only
input: AppReviewCodeAddInput!		 AppReviewCodeAddPayload Adds an App Review code that signs in as its own test account (AppReviewCode), created if need be, and turns App Review on for 14 days (longer where it is already on longer). requires audience:admin:* or platform:admin:*
approveMcpConnection staffql only
input: McpConnectionApproveInput!		 McpConnectionApprovePayload Approves an MCP client’s OAuth connection for the audience: mints its diagnostics:read service token and returns the address that takes the browser back to the client. requires audience:admin:*
banAudienceMember staffql only
input: AudienceMemberBanInput!		 AudienceMemberBanPayload Kicks a member and keeps them out: they can’t sign in on the audience or chat in its venues until unbanned. requires audience:moderate:*
blockUser
input: BlockedUserAddInput!		 BlockedUserAddPayload Blocks someone: neither sees the other’s chat messages, presence, pings or whereabouts any more. They aren’t told. The audience’s admins are, in the console’s Reports queue. requires users:write:self
bookPromoPlacement staffql only
input: PromoPlacementBookInput!		 PromoPlacementBookPayload Books a venue, or an event at one, as a promoted card in its city for a run of nights, at the public rate card price less any discount. Fails when a night is sold out or the venue would hold too many nights. requires audience:write:*
cancelSafetyAlert
input: SafetyAlertCancelInput!		 SafetyAlertCancelPayload Cancels your open safety alert: you’re OK now. Staff on shift are told. requires users:write:self
checkAiProvider staffql only
input: AiProviderLinkCheckInput!		 AiProviderLinkCheckPayload Checks the audience’s stored key for an AI provider with the provider, without changing anything there. Records when it last worked, or why it failed (AIProviderLink.lastError). requires audience:admin:*
checkContacts
input: ContactsCheckInput!		 ContactsCheckPayload Checks the hashed contacts from the viewer’s phone (ContactMatching: SHA-256 hex of “first|last|+E164”, one per number; contacts without a first and last name left out) and turns matching on. Replaces their last check. Once a day. requires users:write:self
createAppReviewCode staffql only

SubmissionKind

  • CLOSED A venue that has closed for good.
  • CORRECTION A fix to a venue’s or event’s details.

  • TRIBE_SUGGESTION A tribe for the audience’s curated list (the picker’s “Suggest a tribe”). About nothing listed; approving it adds the tribe.
