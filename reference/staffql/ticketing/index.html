Ticketing

An audience’s connections to ticketing partners, and the partners it can connect.

Root fields

Section titled “Root fields”
Field Type Description
ticketing IAudienceTicketing! The instance’s IAudienceTicketing mixin. Left out of the schema where its module isn’t installed.

Mutations

Section titled “Mutations”
Operation Returns Description
connectEventbrite staffql only
input: EventbriteConnectInput!		 EventbriteConnectPayload Starts connecting an organizer’s Eventbrite account. Send the organizer to authorizeUrl; after they approve, Eventbrite returns them to returnTo with eventbrite=connected (or denied, or error) and their upcoming events are imported. requires ticketing:write:*
disconnectTicketingAccount staffql only
input: TicketingAccountDisconnectInput!		 TicketingAccountDisconnectPayload Disconnects a ticketing account and stops its webhook. Events imported from it stay. requires ticketing:write:*
matchVenueTicketmaster staffql only
input: VenueMatchTicketmasterInput!		 VenueMatchTicketmasterPayload Links a venue to its Ticketmaster venue, so the scheduled import reads its Ticketmaster events. Without ticketmasterVenueId, looks it up by name near the venue. requires ticketing:write:*
pushEventToEventbrite staffql only
input: EventPushToEventbriteInput!		 EventPushToEventbritePayload Puts an event created in the console on Eventbrite now: a draft the first time, updated after that. With publish, it goes public too, once it has tickets on Eventbrite; the organizer’s “Add to Facebook” setting on Eventbrite then puts it on their Facebook Page. requires ticketing:write:*
updateTicketingAccount staffql only
input: TicketingAccountUpdateInput!		 TicketingAccountUpdatePayload Changes a connected ticketing account, and with sync imports its events again now. requires ticketing:write:*

EventListing

Section titled “EventListing”

Object · implements IAdmissionOffer, Node

An event’s copy on a ticketing partner, which sells tickets to it (an IAdmissionOffer). Its sync details (lastError, pulledAt, pushedAt) are for admins; null for everyone else.

Field Type Description
externalId String! The partner’s ID for the event.
id ID! The ID of the listing.
lastError String Why the last push failed, if it did. requires ticketing:read:*
origin EventListingOrigin! Which side owns its details.
price Money What it costs the buyer, all in (the lowest price for tickets). Null when the seller does not say.
provider String! eventbrite or ticketmaster.
pulledAt ISO8601DateTime When it was last read from the partner. requires ticketing:read:*
pushedAt ISO8601DateTime When it was last sent to the partner. requires ticketing:read:*
seller IProvider! Who sells it: a ticketing partner, or AudienceKit itself.
status String The partner’s status, e.g. draft, live or canceled.
url String Its page on the partner.

TicketingAccount

Section titled “TicketingAccount”

Object · implements Node

An organizer’s account on a ticketing partner, connected to the audience. Its token is never returned.

Field Type Description
id ID! The ID of the account.
lastError String Why the last sync or webhook setup failed, if it did.

name String The organization name on the partner.
provider String! eventbrite.
publishToPartner Boolean! Whether events created in the console are pushed to it as drafts.
webhookConnected Boolean! Whether the partner notifies us of changes.
