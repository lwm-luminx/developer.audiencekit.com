Facebook

The audience’s own Facebook Page, the Facebook apps its people sign in with, and finding Pages and Meta metro areas to link.

Root fields

Section titled “Root fields”
Field Type Description
facebook IAudienceFacebook! The instance’s IAudienceFacebook mixin. Left out of the schema where its module isn’t installed.

Mutations

Section titled “Mutations”
Operation Returns Description
refreshPage staffql only
input: PageRefreshInput!		 PageRefreshPayload Refreshes a venue’s or person’s Page from Facebook now instead of waiting for the scheduled refresh. requires facebook:write:*

FacebookProfile

Section titled “FacebookProfile”

Object · implements IFacebookProfile

The Facebook module’s view of a venue, person or locale.

Field Type Description
facebookId String Its Facebook Page’s ID. A string: Page IDs overflow Int.
isLiked Boolean! Whether the signed-in user likes its Facebook Page.
link String Canonical Facebook Page, profile, or public group URL.
metro MetaMetro The Meta metro area a locale sits in, if linked.
page Page Its Facebook Page, if it has one; talent added by name has none yet.

FacebookSearchResult

Section titled “FacebookSearchResult”

Object · staffql only

A Facebook Page or profile that can be linked to talent.

Field Type Description
avatarUrl staffql only PhotoURL Profile picture.
category staffql only String Page category, e.g. Musician/band.
entityType staffql only String! page, profile, group, or unknown.
facebookId staffql only String! Facebook id, or the username when only that is known.
link staffql only String Facebook URL.
location staffql only String City and region of a Page with a location.
lookupSource staffql only String! facebook, manual, or staff (group confirmation).
name staffql only String Name on Facebook; null when Facebook would not share it.
readable staffql only Boolean! False when Facebook would not share this profile; linking it needs a name.
verified staffql only Boolean! Whether Facebook has verified the Page.

MetaMetro

Section titled “MetaMetro”

Object

A Meta metro area (a Nielsen DMA, Meta’s geo_market), as Facebook ad targeting names it.

Field Type Description
countryCode String Its country, e.g. US. Only on search results.
key String! Meta’s key for it, e.g. DMA:819.
name String Its name on Meta, e.g. Seattle-Tacoma (WA).

Page

Section titled “Page”

Object · implements HasBanner, HasPhoto, HasTimestamps, Node

A Facebook Page associated with a listing.

Field Type Description
about String The Facebook Page’s About text.
address String The Facebook Page’s address, on one line.
bannerUrl PhotoURL The banner’s CDN URL, if there is one.
category String The Facebook Page’s category, such as Gay Bar.
createdAt ISO8601DateTime! When the record was created.
facebookEntityType String! page, profile, or group.
facebookId String! Its Facebook ID. A string: Page IDs overflow Int.
facets String Facets associated with this Facebook Page.
id ID! Unique identifier.
lastUpdateError String Why Facebook refused the last refresh. Null when it succeeded.
link String The Facebook Page itself.
name String! Display name.
phone String The Facebook Page’s phone number.
photoUrl PhotoURL The photo’s CDN URL, if there is one.
syncedAt ISO8601DateTime When it was last refreshed from Facebook (or the refresh last failed).
updatedAt ISO8601DateTime! When the record was last updated.
website String The website the Facebook Page links to.
