Locales

Root fields

Section titled “Root fields”
Field Type Description
closestLocale
near: CoordinatesInput!		 Locale The locale nearest a position.
locale
id: ID!		 Locale A locale in the audience by its UUID.
locales [Locale!]! Locales belonging to this audience.

Mutations

Section titled “Mutations”
Operation Returns Description
addLocaleGuide staffql only
input: LocaleGuideAddInput!		 LocaleGuideAddPayload Links a local guide (a city’s LGBTQ+ guide, a nightlife listing, a community calendar) to one of the audience’s locales. Research reads a locale’s guides first when it looks for venues and events there. Adding a link it already has updates its title and note. requires locales:write:* or locales:admin:mine
createLocale staffql only
input: LocaleCreateInput!		 LocaleCreatePayload Adds a locale to the audience: a city or neighborhood its venues are in. requires locales:write:*
deleteLocale staffql only
input: LocaleDeleteInput!		 LocaleDeletePayload Deletes one of the audience’s locales. Its venues must be moved or deleted first. requires locales:write:*
mergeLocale staffql only
input: LocaleMergeInput!		 LocaleMergePayload Moves a locale into another locale in this audience, preserving its records and deleting the source. requires locales:write:*
removeLocaleGuide staffql only
input: LocaleGuideRemoveInput!		 LocaleGuideRemovePayload Unlinks a local guide from its locale, so research no longer reads it. requires locales:write:* or locales:admin:mine
updateLocale staffql only
input: LocaleUpdateInput!		 LocaleUpdatePayload Changes one of the audience’s locales. requires locales:write:*

Objects

Section titled “Objects”

Locale

Section titled “Locale”

Object · implements HasBanner, HasTimestamps, Node

A geographic area containing venues and featured people.

Field Type Description
accessGrants staffql only [AccessGrant!]! Permissions granted on this locale to specific principals. requires locales:read:mine or locales:admin:*
bannerUrl PhotoURL A photo of the place, for the top of its screens.
beaconMajor Int The major identifier of the locale beacon.
chat ILocaleChat! The instance’s ILocaleChat mixin. Left out of the schema where its module isn’t installed.
chatRetentionMinutes Int! How many minutes its chat room shows a message before it expires.
cityNames [String!]! Cities and neighborhoods it covers.
createdAt ISO8601DateTime! When the record was created.
envelope GeoJSON The geographic boundary of this place.
events ILocaleEvents! The instance’s ILocaleEvents mixin. Left out of the schema where its module isn’t installed.
friends ILocaleFriends! The instance’s ILocaleFriends mixin. Left out of the schema where its module isn’t installed.
guides staffql only [LocaleGuide!]! Local guides linked to it (a city’s LGBTQ+ guide, a nightlife listing), which research reads first when it looks for venues and events here.
id ID! Unique identifier.
label String Short label for the locale.
liquor ILocaleLiquor! The instance’s ILocaleLiquor mixin. Left out of the schema where its module isn’t installed.
location Location The geographic location of this place.
name String Display name.
people ILocalePeople! The instance’s ILocalePeople mixin. Left out of the schema where its module isn’t installed.
posts IPosts! The instance’s IPosts mixin. Left out of the schema where its module isn’t installed.
profile IListingProfile! The instance’s IListingProfile mixin. Left out of the schema where its module isn’t installed.
rooms staffql only IRooms The instance’s IRooms mixin, when available to the viewer. requires rooms:read:member
timeZone String! Its IANA time zone, e.g. America/Los_Angeles; Etc/UTC until it is known.
updatedAt ISO8601DateTime! When the record was last updated.
venues ILocaleVenues! The instance’s ILocaleVenues mixin. Left out of the schema where its module isn’t installed.

LocaleGuide

Section titled “LocaleGuide”

Object · staffql only

A local guide linked to a locale (a city’s LGBTQ+ guide, a nightlife listing, a community calendar). Research reads a locale’s guides first when it looks for venues and events there.

Field Type Description
createdAt staffql only ISO8601DateTime! When it was linked.
createdBy staffql only User Who linked it.
id staffql only ID! Unique identifier.
note staffql only String What it is good for, which research reads as a hint.
title staffql only String What staff call it.
updatedAt staffql only ISO8601DateTime! When it last changed.
url staffql only String! The guide, an http(s) link.

Location

Section titled “Location”

Object · implements HasBanner, HasPhoto, HasTimestamps, Node

A geographic place and its provider details.

Field Type Description
address String Its full address.
bannerUrl PhotoURL The banner’s CDN URL, if there is one.
createdAt ISO8601DateTime! When the record was created.
envelope Geography The geographic boundary of this place.
id ID! Unique identifier.
photoUrl PhotoURL The photo’s CDN URL, if there is one.
places IPlacesProfile! The instance’s IPlacesProfile mixin. Left out of the schema where its module isn’t installed.
point Geography The geographic point of this place.
updatedAt ISO8601DateTime! When the record was last updated.

LocaleInput

Section titled “LocaleInput”

Input · staffql only

A locale’s details. Fields left out are not changed.

Field Type Description
beaconMajor staffql only Int iBeacon major number for its venues.
cityNames staffql only [String!] Cities and neighborhoods it covers.
googlePlaceId staffql only String Its Google place ID (a city or region), from Query.places.search. Its name, center and time zone come from Google when the server has a Google API key.
label staffql only String Short key, e.g. “seattle”. Defaults from the name.
metaMetro staffql only MetaMetroInput The Meta metro area it sits in, for Facebook targeting. Null unlinks it.
name staffql only String Its name, e.g. “Seattle”. Required to create one.
timeZone staffql only String Its IANA time zone, e.g. America/Los_Angeles. Left out when creating one, it comes from its Google place, else the zone the audience’s other locales share, else Etc/UTC.
