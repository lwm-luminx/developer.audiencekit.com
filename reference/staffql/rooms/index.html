Rooms

The rooms module’s root lookups: the rooms you’re in, and one room. A venue’s or event’s own room is on it (Venue.rooms, Event.rooms).

Root fields

Section titled “Root fields”
Field Type Description
rooms staffql only IAudienceRooms! The instance’s IAudienceRooms mixin. Left out of the schema where its module isn’t installed.

Mutations

Section titled “Mutations”
Operation Returns Description
addRoomChecklistItem staffql only
input: RoomChecklistItemAddInput!		 RoomChecklistItemAddPayload Adds an item to a room’s checklist, at the end. Anyone in the room may. Name the room, or the venue, event or locale whose back-of-house room it is. requires rooms:write:member
finishRoomUpload staffql only
input: RoomUploadFinishInput!		 RoomUploadFinishPayload Confirms an upload to a room (startRoomUpload) reached storage whole, so it can be shared. Only its uploader. requires rooms:write:member
nudgeRoomTrack staffql only
input: RoomTrackNudgeInput!		 RoomTrackNudgePayload Asks an act on an event’s lineup for its track: posts a “Track needed” card in the event’s back-of-house room (kind TRACK_NEEDED), as the venue when the caller manages it, and pushes whoever manages the act’s listings. The venue’s managers and staff, admins and the event’s hosts may (RoomAccess#runs?). requires rooms:write:member
promoteRoomFile staffql only
input: RoomFilePromoteInput!		 RoomFilePromotePayload Posts a picture shared in a back-of-house room to its venue’s public chat, as a photo with a caption and alt text (RoomPromotion). The room keeps its copy, marked promoted. The venue and admins post any picture as the venue; talent post a picture they shared, as one of their listings in the room (asPersonId). requires rooms:write:member
removeRoomChecklistItem staffql only
input: RoomChecklistItemRemoveInput!		 RoomChecklistItemRemovePayload Removes an item from a room’s checklist. Whoever added it may, and the venue and admins. requires rooms:write:member
removeRoomFile staffql only
input: RoomFileRemoveInput!		 RoomFileRemovePayload Deletes a file shared in a room, and its stored copy. Its uploader may, and the venue’s managers and admins. requires rooms:write:member
removeRoomMessage staffql only
input: RoomMessageRemoveInput!		 RoomMessageRemovePayload Removes something said or posted in a room, with its replies and the files it shared. Its writer may, and the venue’s managers and admins. requires rooms:write:member
sendRoomMessage staffql only
input: RoomMessageSendInput!		 RoomMessageSendPayload Says something in a room, or posts there (kind POST, with a title, which can be pinned and replied to), sharing the files uploaded for it (startRoomUpload). Name the room, or the venue, event or locale whose back-of-house room it is. requires rooms:write:member
setRoomTrackNeeded staffql only
input: RoomTrackNeededSetInput!		 RoomTrackNeededSetPayload Says whether an act on an event’s lineup needs a track in the event’s back-of-house room. Performers’ acts need one unless someone says not; others don’t unless someone says they do. The venue’s managers and staff, admins, the event’s hosts and the act’s own people may (RoomAccess#trusted_with?). requires rooms:write:member
startRoomUpload staffql only
input: RoomUploadStartInput!		 RoomUploadStartPayload Starts uploading a file to a room: PUT its bytes to uploadUrl within 30 minutes, with the same Content-Type (or, from a browser, POST them in partSize parts to partsPath), then confirm it (finishRoomUpload) and share it (sendRoomMessage fileIds). Sound, pictures, video and documents (PDF, text, office files, zip), up to 200 MB. A file not shared within a day is deleted. Name the room, or the venue, event or locale whose back-of-house room it is. requires rooms:write:member
updateRoomChecklistItem staffql only
input: RoomChecklistItemUpdateInput!		 RoomChecklistItemUpdatePayload Ticks, unticks or rewords an item on a room’s checklist. Fields left out are not changed. Anyone in the room may tick; whoever added it, the venue and admins may reword it. requires rooms:write:member
updateRoomMessage staffql only
input: RoomMessageUpdateInput!		 RoomMessageUpdatePayload Changes something said or posted in a room, or pins or unpins a post. Fields left out are not changed. Its writer may, and the venue’s managers and admins. requires rooms:write:member

Subscriptions

Section titled “Subscriptions”
Operation Returns Description
room staffql only
id: ID!		 RoomEvent! Follows a room you’re in: an event whenever something said or posted there is added, changed (edited, pinned, a reply or file added) or removed, while you’re still in it. Nothing arrives on subscribing. requires rooms:read:member

Room

Section titled “Room”

Object · staffql only

A private room on a venue, an event or a locale, where the people working it talk, post and share files (doc/ROOMS.md). A locale’s room holds the staff of every venue in it. A venue’s or locale’s room keeps its messages for 90 days and its pinned posts however old; an event’s room closes 24 hours after the event ends, and is deleted then with what was said and shared.

Field Type Description
checklist staffql only [RoomChecklistItem!]! Its checklist: in an event’s room the items that tick themselves first, then what its people added, in order.
event staffql only Event The event it’s on; null for a venue’s or locale’s room.
expiresAt staffql only ISO8601DateTime When an event’s room closes: 24 hours after the event ends. Null for a venue’s or locale’s room.
files staffql only
after: String
appearanceId: ID
before: String
first: Int
kind: RoomFileKind
last: Int		 RoomFileConnection! The files shared there, newest first.
id staffql only ID! Its UUID.
kind staffql only RoomKind! What it is for.
lastMessageAt staffql only ISO8601DateTime When someone last posted.
lineup staffql only [RoomSlot!]! An event room’s lineup in running order, with each act’s track; empty in a venue’s room.
locale staffql only Locale The locale it’s on, for a locale’s room.
members staffql only [RoomMember!]! Everyone in it, the strongest role first, then by name.
messages staffql only
after: String
before: String
first: Int
kind: RoomMessageKind
last: Int		 RoomMessageConnection! What was said there, newest first, without replies (a post’s are on it).
name staffql only String The name of the venue, event or locale.
pinned staffql only [RoomMessage!]! Its pinned posts, newest pinned first.
venue staffql only Venue The venue it is on, or the event’s venue; null for a locale’s room.
viewerCanPostAsVenue staffql only Boolean! Whether the signed-in user may post as a venue: the venue’s managers and the audience’s admins; in a locale’s room the managers of a venue there (viewerVenues).
viewerPeople staffql only [Person!]! The talent the signed-in user may post as here.
viewerVenues staffql only [Venue!]! The venues the signed-in user may post as here (sendRoomMessage asVenue, asVenueId): the venue, or in a locale’s room the venues there they manage.

RoomFile

Section titled “RoomFile”

Object

A file shared in a room. Only its members can download it, through a link that works for an hour.

Field Type Description
appearance Appearance The lineup slot it’s for, if any.
audioCodec String A sound file’s codec, as the server read it, such as mp3, aac or pcm_s16le; null until it is READY.
audioError String Why a sound file was REJECTED, to show its uploader.
audioStatus RoomFileAudioStatus Where the server’s check of a sound file has got to; null for files that aren’t sound.
byteSize BigInt! Its size in bytes.
channels Int A sound file’s channels (1 mono, 2 stereo); null until READY.
contentType String! Its MIME type.
createdAt ISO8601DateTime! When it was uploaded.
durationMs Int A sound file’s length in milliseconds, as the server decoded it; null until it is READY.
durationSeconds Int A sound file’s length: once it’s READY, as the server decoded it; until then, as the uploading app said; null if neither knows or it was REJECTED.
id ID! Its UUID.
kind RoomFileKind! What kind of file it is.
label RoomFileLabel What a document is, if its uploader said.
messageId ID The message it was shared with; null until it’s shared.
name String! Its file name, as uploaded.
promotedAt ISO8601DateTime When a picture was posted to the public chat (promoteRoomFile); null if it never was.
sampleRate Int A sound file’s samples a second, such as 44100; null until READY.
uploaded Boolean! Whether the upload was confirmed (finishRoomUpload).
uploaderName String Who uploaded it: their full name.
url String A link that downloads it, working for an hour; null until it is uploaded.
viewerCanPromote Boolean! Whether the signed-in user may post it to the public chat: a picture not posted yet, by the venue and admins, or by the talent who shared it.
viewerCanRemove Boolean! Whether the signed-in user may delete it (removeRoomFile): its uploader, the venue’s managers and admins.
waveform [Int!] A sound file’s waveform: 120 peaks evenly over its length, each from 0 to 100, the loudest 100 (all 0 for silence). To draw fewer bars, take the loudest of each run of neighbours. Null until READY.
