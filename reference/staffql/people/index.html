Appearance

Section titled “Appearance”

Object · implements Node

An entry in a lineup: someone (or several people) on, or an intermission. A lineup is a venue night’s own, built as the night goes, or an event’s, built ahead. Each runs in position order and can be advanced like a slide deck (advanceLineup).

Field Type Description
activity AppearanceActivity A segment or intermission: what runs in the venue’s chat while it’s on; null for nothing.
afterScene Scene A break inside an act: the scene it follows.
cameOffAt ISO8601DateTime When advancing (or finishing it) took it off.
curtainCallMinutes Int An act the curtain rises on: places is called this many minutes before it (or once it is up next), and it goes on only on a go (goNoGo). Null: no curtain call.
durationMinutes Int endTiming DURATION: how long it runs once on.
endTiming AppearanceEndTiming! How it ends.
endsAt ISO8601DateTime Its set end time; null until close or advanced.

entryKind AppearanceKind! What it is: an act, an intermission or a segment.
estimatedMinutes Int How long it is expected to run: its set length, else an act’s scenes or tracks plus other time; null when nothing says.
event Event The event whose lineup it’s on, built ahead; null for one on the venue night’s own lineup.
extraMinutes Int An act: time beyond its scenes or tracks, as set; null for the default (10 minutes).
flexible Boolean! Whether it stretches or shrinks to bring the show back on time.
goNoGo GoNoGo An act’s curtain call go/no-go: who is ready. Null without a curtain call, and for anyone not working the show.

Lineup

Section titled “Lineup”

Object · implements Node

One show (doc/LINEUP_MODEL.md): a venue zone’s night, open to close, with its own acts and breaks and each event in the zone as one step; or an event’s in a zone, a child of that night. It has hosts; its acts are scenes of performers. The show goes from preshow to the host to each scene (back to the host, by setting) to postshow.

Field Type Description
children [Lineup!]! A zone’s night: its events’ lineups in this zone, as they start.
closesAt ISO8601DateTime When it closes: a zone night’s close, an event’s end.
current LineupStep The step on now; null while the host has it.
endedAt ISO8601DateTime When the show ended, if it has.
entries [Appearance!]! Its entries in order: acts, breaks, and the host and clock-run entries made before lineups.
event Event The event whose lineup it is; null for a zone’s night.
goNoGo GoNoGo The go/no-go of the act whose curtain the next advance raises. Null otherwise, and for anyone not working the show.

Where importLineup puts the entries of a file.

  • APPEND After the lineup’s entries.
  • REPLACE In place of the lineup’s entries (not its karaoke singers). Refused once any of it has been on.

LineupPhase

Section titled “LineupPhase”

Enum

Where a lineup’s show stands (doc/LINEUP_MODEL.md).

  • BREAK An intermission or segment is on.
  • ENDED Over: an event’s has ended, a zone’s night has closed.
  • EVENT A zone’s night: one of its events is on (see its lineup).
  • HOST The host has the stage: between scenes, and at the start and end.
  • POSTSHOW An event’s, after the show ends until the event does. Breaks after the last scene run now.
  • PRESHOW Before “Start the show” (an event’s, from its start; a zone’s night, before it opens). Breaks before the first scene run now.
  • SCENE A scene is on.
  • SCHEDULED An event’s: its event hasn’t started; the zone’s night is on.

LineupStepKind

Section titled “LineupStepKind”

Enum

What a step of a show is.

  • EVENT In a zone’s night: an event’s lineup, as one element.
  • INTERMISSION An intermission: a break between scenes.
  • SCENE A scene of an act: one or more performers.
  • SEGMENT A segment, e.g. trivia or photos with the cast.

LineupTaskAuto

Section titled “LineupTaskAuto”

Enum

What ticks a task by itself.

  • TRACK A track is in for the act: a sound file shared for it in a back-of-house room, or one on each of its scenes. Applies only to acts that need a track.

LineupTaskSource

Section titled “LineupTaskSource”

Enum

Where a lineup entry’s task comes from (LineupTasks).

  • ENTRY Added to this entry alone.
  • EVENT The event’s task templates.
  • SERIES The event series’ task templates.
  • TALENT A performer’s on it, or their troupe’s billed on the event.
  • VENUE The venue’s task templates.

PersonVisibility

Enum

Who sees a performer (PerformerVisibility). Places are public; people are Community unless they opt in.

  • COMMUNITY Anyone signed in to the app (free). The default.
  • PUBLIC The whole internet: share cards, App Clips and the web included.

ReadinessArea

Section titled “ReadinessArea”

Enum

Who a go/no-go answer is about.

  • STAFF Someone on the support staff.
  • TALENT A person on the acts the curtain rises on.
  • VENUE The venue.

ReadinessState

Section titled “ReadinessState”

Enum

Whether someone is ready for the curtain.

  • NOT_READY Not ready: the show waits.
  • OVERRIDDEN The venue said go for them (Velvet “Override: go”): counts as ready, but is not their own answer. Only the venue or the hosts set it.
  • PENDING Not answered yet. Read only.
  • READY Ready.

ShowEndsTo

Section titled “ShowEndsTo”

Enum

What ending a scene (or break) goes to.

  • HOST Back to the host, who brings on what is next.
  • NEXT Straight on to the next scene of the same act, or the break after it. An act always starts from the host.
