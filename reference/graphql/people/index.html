People

The people featured in an audience, and a lookup of one by their UUID.

Root fields

Section titled “Root fields”
Field Type Description
people IAudiencePeople! The instance’s IAudiencePeople mixin. Left out of the schema where its module isn’t installed.

Mutations

Section titled “Mutations”
Operation Returns Description
setReadiness
input: ReadinessSetInput!		 ReadinessSetPayload Says who is ready for a curtain call: the venue, a performer or someone on the support staff. The show runs on GO (advanceLineup waits for it unless forced). requires people:write:mine or people:write:my_troupes or events:write:venue or users:write:self
updateLineupTask
input: LineupTaskUpdateInput!		 LineupTaskUpdatePayload Ticks, unticks, removes, puts back or rewords a lineup entry’s task. Fields left out aren’t changed. Anyone working the show ticks; whoever may change the lineup removes, puts back and rewords (only an entry’s own task has words of its own). requires people:write:mine or people:write:my_troupes or events:write:venue or users:write:self

Appearance

Section titled “Appearance”

Object · implements Node

An entry in a lineup: someone (or several people) on, or an intermission. A lineup is a venue night’s own, built as the night goes, or an event’s, built ahead. Each runs in position order and can be advanced like a slide deck (advanceLineup).

Field Type Description
activity AppearanceActivity A segment or intermission: what runs in the venue’s chat while it’s on; null for nothing.
afterScene Scene A break inside an act: the scene it follows.
cameOffAt ISO8601DateTime When advancing (or finishing it) took it off.
curtainCallMinutes Int An act the curtain rises on: places is called this many minutes before it (or once it is up next), and it goes on only on a go (goNoGo). Null: no curtain call.
durationMinutes Int endTiming DURATION: how long it runs once on.
endTiming AppearanceEndTiming! How it ends.
endsAt ISO8601DateTime Its set end time; null until close or advanced.
endsTo ShowEndsTo What ending it goes to, as set: an act’s scenes unless they say, or a break.
entryKind AppearanceKind! What it is: an act, an intermission or a segment.
estimatedMinutes Int How long it is expected to run: its set length, else an act’s scenes or tracks plus other time; null when nothing says.
event Event The event whose lineup it’s on, built ahead; null for one on the venue night’s own lineup.
extraMinutes Int An act: time beyond its scenes or tracks, as set; null for the default (10 minutes).
flexible Boolean! Whether it stretches or shrinks to bring the show back on time.
goNoGo GoNoGo An act’s curtain call go/no-go: who is ready. Null without a curtain call, and for anyone not working the show.
id ID! Its UUID.
kind AppearanceKind! An act or an intermission. Segments read as INTERMISSION here, for apps built before them (they fail on values they do not know); entryKind has the full kind.
lateMinutes Int How many minutes after its set time it starts, as projected (negative: early); null without a set time.
lineup Lineup The lineup it’s on (doc/LINEUP_MODEL.md): a zone’s night or an event’s in a zone.
maxMinutes Int The longest it runs when it flexes, as set.
minMinutes Int The shortest it runs when it flexes, as set.
missingTracks Int! How many of an act’s scenes have no length or track (each counted as 4 minutes in the estimate).
night ISO8601Date! The venue night it is on.
notes String Notes for the crew, in Markdown.
people

before: String
first: Int

position Int! Its place in its lineup’s running order, from 0.
preshowMinutes Int An act: its own preshow before it, from doors to the host, in minutes.

title String An act’s billing (a duet’s name) or an intermission’s label, if it has one.
triviaDriver TriviaDriver Who moves its trivia along; null unless it runs trivia.
triviaReveal TriviaReveal When its trivia answers show; null unless it runs trivia.

Lineup

Section titled “Lineup”

Object · implements Node

One show (doc/LINEUP_MODEL.md): a venue zone’s night, open to close, with its own acts and breaks and each event in the zone as one step; or an event’s in a zone, a child of that night. It has hosts; its acts are scenes of performers. The show goes from preshow to the host to each scene (back to the host, by setting) to postshow.

Field Type Description
children [Lineup!]! A zone’s night: its events’ lineups in this zone, as they start.
closesAt ISO8601DateTime When it closes: a zone night’s close, an event’s end.
current LineupStep The step on now; null while the host has it.
endedAt ISO8601DateTime When the show ended, if it has.
entries [Appearance!]! Its entries in order: acts, breaks, and the host and clock-run entries made before lineups.
event Event The event whose lineup it is; null for a zone’s night.
goNoGo GoNoGo The go/no-go of the act whose curtain the next advance raises. Null otherwise, and for anyone not working the show.
hosts [Person!]! Its hosts, in billing order.
id ID! Its UUID.
name String! What it’s billed as: its title, the event’s name or the zone’s.
night ISO8601Date! The venue night it runs on.
opensAt ISO8601DateTime When it opens: a zone night’s open, an event’s start.
parent Lineup An event’s: the zone night it is a step of.
phase LineupPhase! Where the show stands.
postshow [LineupStep!]! An event’s breaks after its last scene: on in postshow.
preshow [LineupStep!]! An event’s breaks before its first scene: on in preshow.
sceneEndsTo ShowEndsTo What ending a scene goes to unless the scene or its act says; null: the host.
startedAt ISO8601DateTime When the show started, if it has.
steps [LineupStep!]! What advancing steps through, in order: scenes, breaks between them, and in a zone’s night its events.
title String Its billing, as set.
upNext LineupStep What advancing from the host puts on next.
venue Venue! Where.
zone StageZone Its zone; null for the venue’s default zone.
zoneName String! Its zone’s name: Stage for an unnamed default zone.

endedAt ISO8601DateTime When it ended, if it has.

event Event The event whose show it is; null for the venue’s own.
night ISO8601Date! The venue night it is on.
scheduledEndsAt ISO8601DateTime When it was scheduled to end: its event’s end, else when its last entry is expected off.
viewerModeratesAsCast Boolean! Whether you moderate the venue chat now as its cast (castModeratesUntil).

What runs by itself in the venue’s chat while a segment or intermission is on.

Enum

How a lineup entry ends.

  • ADVANCE When the venue advances to what is next.
  • CLOSE When the night ends.
  • DURATION durationMinutes after it goes on, or when the venue advances, whichever is first.
  • TIME At its end time.

AppearanceKind

Section titled “AppearanceKind”

Enum

What a lineup entry is.

  • ACT Someone (or several people) on: hosting, DJing, performing or MCing.
  • INTERMISSION A break in the show.
  • SEGMENT A generic time block with a title, e.g. “Photos with cast” for 10 minutes after an act (endTiming DURATION). It and an intermission can run an activity.

AppearanceRole

Section titled “AppearanceRole”

Enum

What someone is doing at a venue.

  • DJ DJing.
  • HOST Hosting.
  • MC MCing.
  • PERFORMER Performing, e.g. a drag or live act.
  • SINGER Singing karaoke: a signup, with its song as songRequest.

AppearanceStartTiming

Enum

How a lineup entry starts.

  • HARD At its time, by the clock (or earlier, if advanced to).
  • NONE No set time: when the venue advances to it.
  • SOFT Around its time: when the venue advances to it.

AppearanceState

Section titled “AppearanceState”

Enum

Where a lineup entry is in its night.

  • DONE Finished, or its night is over.
  • ON On now.
  • UPCOMING Hasn’t gone on yet.

GoNoGoVerdict

Section titled “GoNoGoVerdict”

Enum

Where a curtain call’s go/no-go stands.

  • GO Everyone is ready: advancing raises the curtain.
  • NO_GO Someone said not ready.
  • PENDING Some haven’t answered yet.

LineupPhase

Section titled “LineupPhase”

Enum

Where a lineup’s show stands (doc/LINEUP_MODEL.md).

  • BREAK An intermission or segment is on.
  • ENDED Over: an event’s has ended, a zone’s night has closed.
  • EVENT A zone’s night: one of its events is on (see its lineup).
  • HOST The host has the stage: between scenes, and at the start and end.
  • POSTSHOW An event’s, after the show ends until the event does. Breaks after the last scene run now.
  • PRESHOW Before “Start the show” (an event’s, from its start; a zone’s night, before it opens). Breaks before the first scene run now.
  • SCENE A scene is on.
  • SCHEDULED An event’s: its event hasn’t started; the zone’s night is on.

LineupStepKind

Section titled “LineupStepKind”

Enum

What a step of a show is.

  • EVENT In a zone’s night: an event’s lineup, as one element.
  • INTERMISSION An intermission: a break between scenes.
  • SCENE A scene of an act: one or more performers.
  • SEGMENT A segment, e.g. trivia or photos with the cast.

LineupTaskAuto

Enum

What ticks a task by itself.

  • TRACK A track is in for the act: a sound file shared for it in a back-of-house room, or one on each of its scenes. Applies only to acts that need a track.

LineupTaskSource

Where a lineup entry’s task comes from (LineupTasks).

  • ENTRY Added to this entry alone.
  • EVENT The event’s task templates.
  • SERIES The event series’ task templates.
  • TALENT A performer’s on it, or their troupe’s billed on the event.
  • VENUE The venue’s task templates.

PersonKind

Section titled “PersonKind”

Enum

What a listing is (doc/ORGANIZERS.md).

  • ORGANIZATION An organization that presents events, like a pride center: on its events as ‘Presented by’ (Event.people.organizers), not on People, and always Public.
  • TALENT A performer, host or troupe: on People. The default.

  • COMMUNITY Anyone signed in to the app (free). The default.
  • PUBLIC The whole internet: share cards, App Clips and the web included.

Enum

Who a go/no-go answer is about.

  • STAFF Someone on the support staff.
  • TALENT A person on the acts the curtain rises on.
  • VENUE The venue.

ReadinessState

Section titled “ReadinessState”

Enum

Whether someone is ready for the curtain.

  • NOT_READY Not ready: the show waits.
  • OVERRIDDEN The venue said go for them (Velvet “Override: go”): counts as ready, but is not their own answer. Only the venue or the hosts set it.
  • PENDING Not answered yet. Read only.
  • READY Ready.

RoomFileAudioStatus

Section titled “RoomFileAudioStatus”

Enum

Where the server’s check of a sound file shared in a room has got to.

  • PENDING Uploaded; the server is checking it. Its length is what the uploading app said, and it has no waveform yet.
  • READY It plays. Its length, format and waveform are what the server read.
  • REJECTED It isn’t sound that plays: audioError says why.

  • IMAGE A picture, such as a poster.
  • VIDEO A video.
