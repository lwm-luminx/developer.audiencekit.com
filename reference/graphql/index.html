GraphQL reference

The consumer view is the audience graph as POST /v1/audience/:audience_id/graphql serves it to an audience’s own apps: a signed-in member gets their own records and the audience’s public ones, whatever their role. Fields no member could use aren’t in this schema at all. Staff tools use StaffQL instead; GraphQL explains the two endpoints.

The Swift and Kotlin SDKs wrap the common queries of this view.

Download the dumps: SDL and introspection (main-20261106T194756-c4c448c), or the next branch’s: SDL and introspection.

Modules

Section titled “Modules”

A module adds its edge to the root and to the records it extends. An audience that hasn’t installed a module has no edge for it, so its fields aren’t refused, they don’t exist; ask the schema (__type) before relying on one, or let the SDKs do it.

Audience

Section titled “Audience”

The query root is the audience itself. An audience: its listings, members and configuration. On an audience’s endpoints it is the query root.
