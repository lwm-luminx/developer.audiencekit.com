Chat

The chat module’s root lookups: the audience’s rooms, a room’s transcript and bans, and the moderators an audience can use.

Root fields

Section titled “Root fields”
Field Type Description
chat IAudienceChat! The instance’s IAudienceChat mixin. Left out of the schema where its module isn’t installed.

Mutations

Section titled “Mutations”
Operation Returns Description
removeMyChatMessage
input: ChatMessageRemoveOwnInput!		 ChatMessageRemoveOwnPayload Removes one of your own messages from its chat room. Everyone in the room stops seeing it at once. requires chat:write:self
reportChatMessage
input: ChatMessageReportInput!		 ChatMessageReportPayload Reports a message in a venue’s or locale’s chat room to the audience’s admins, who see it in the console’s Reports queue at once and can remove it or ban the sender. Optionally blocks the sender too. A post as the venue or as a person can be reported like any other; blocking ignores it, since a listing has no sender to block. Same as reportContent with MESSAGE. requires chat:write:self
sendMyChatMessage
input: ChatMessageSendOwnInput!		 ChatMessageSendOwnPayload Says something in a chat room as yourself. The message reaches everyone following the room at once. requires chat:write:self or chat:write:venue

Subscriptions

Section titled “Subscriptions”
Operation Returns Description
localeChat
localeId: ID!
watch: Boolean		 ChatRoomEvent! Follows a locale’s chat room, for people out in the locale and not at a venue: ChatJoined, then everything the room says and who comes and goes, until ChatLeft. The room’s admins join from anywhere. requires chat:read:self
venueChat
venueId: ID!
watch: Boolean		 ChatRoomEvent! Follows a venue’s chat room: ChatJoined, then everything the room says and who comes and goes, until ChatLeft. Open to people at the venue, and to the room’s admins from anywhere. requires chat:read:self or chat:read:venue

Section titled “Objects”

ArbiterGuardPolicy

Section titled “ArbiterGuardPolicy”

Object

One of Arbiter’s guard policies about the AI host, and the score it flags at for the audience.

Field Type Description
default Float! The score it flags at unless someone sets another.
key String! The policy, e.g. rule_override.
name String! What it checks, for people.
overridden Boolean! Whether someone set its score.
value Float! The score (0 to 1) it flags at.

ArbiterModerationProvider

Section titled “ArbiterModerationProvider”

Object · implements IModerationProvider, IProvider

Arbiter (Moderation::Arbiter, key moderation_lmstudio): the moderator and AI host (Glam) that runs on someone’s own Mac with local models, following the moderation feed over a websocket. How it judges and hosts for the audience is set in the Moderation plugin’s settings.

Field Type Description
actions [String!]! Actions it can take, e.g. escalate or remove_message. An audience grants it some of them.
categories [String!]! Policy categories it judges, e.g. spam or threats.
events [String!]! Chat events it receives, e.g. message.created or user.joined.
following Boolean! Whether it reads this audience’s chat now: always for inline ones; for remote ones, while a live service token of the audience’s is issued for it with chat:moderate:*.
inline Boolean! Whether it receives each event on this server as it happens.
key String! Its key, e.g. karafun.
name String! Its name, e.g. KaraFun.
remote Boolean! Whether it runs on its own server and dials in for the event feed.
settings ArbiterModerationSettings How Arbiter judges and hosts for the endpoint audience. Admins only; null for everyone else. requires audience:admin:*

ArbiterModerationSettings

Section titled “ArbiterModerationSettings”

Object

How Arbiter judges and hosts for an audience, set in the console’s Moderation plugin. Unset values show their defaults; the Mac keeps its own value for anything nobody has set yet.

Field Type Description
alpha Float! The conformal sets’ error rate (0.01 to 0.3): lower makes more answers unsure.
configured Boolean! Whether anyone has set anything yet.
coverageThreshold Float! Under this share of the answer on true/false (0.1 to 0.9), a check is unscored and goes to a person.
evaluationTypes [String!]! The evaluation queue’s work types Arbiter’s worker takes.
glamMode String! What Glam, the AI host, does: shadow (drafts, posts nothing), approve (a person approves each step) or live.
guardPolicies [ArbiterGuardPolicy!]! The guard’s policies about the AI host, with the score each flags at.
hostAvatar String! The AI host’s picture in the chats, an https URL; blank for Glam’s.
hostName String! What the AI host is called in the chats and its own prompt (default Glam).
prompts [ArbiterPrompt!]! The prompts Arbiter’s models are shown, as this audience has them.
roomGuidelines String! What Glam’s “Re-show guidelines” posts.
rules [ArbiterRule!]! The moderation rules (config/moderation/matchers.yml), with the score each is acted on at per venue rating.
rulesEnabled Boolean! Whether the moderation rules are checked.
rulesModel String! Which model judges the rules: guard (fast) or decisions.
updatedAt ISO8601DateTime When someone last changed them.
venueRating String! Which rules’ thresholds apply: general (all ages) or adult.
workTypes [String!]! The work types there are to choose from.

ArbiterPrompt

Section titled “ArbiterPrompt”

Object

One of the prompts Arbiter’s models are shown, as this audience has it: the repo’s default or the audience’s own. {{host_name}} and {{app_name}} are filled in by the server, the arguments by the Mac.

Field Type Description
arguments [String!]! The {{variables}} the Mac fills in, besides the server’s.
body String! The template as this audience has it.
defaultBody String! The repo’s default (config/arbiter/prompts).
description String! Where it is used.
digest String! The first 16 hex digits of the body’s SHA-256, as traces record.
name String! The template, e.g. glam.system.
overridden Boolean! Whether this audience changed it.
updatedAt ISO8601DateTime When this audience last changed it.
use String! How the Mac uses it: system (the system prompt) or user_suffix (after the chat).
version String! The default’s version, with the audience’s change time when overridden.

ArbiterRule

Section titled “ArbiterRule”

Object

One moderation rule Arbiter checks, and the score it is acted on at for the audience, per venue rating.

Field Type Description
adult Float! The score (0 to 1) it is acted on at in an adult room.
defaultAdult Float! The matchers’ seed score for an adult room.
defaultGeneral Float! The matchers’ seed score for a general room.
general Float! The score (0 to 1) it is acted on at in a general room.
key String! The rule, e.g. identity_hate.
name String! The rule, for people.
overridden Boolean! Whether someone set its scores.

BotSender

Section titled “BotSender”

Software with a name of its own, like Glam, the AI host. Never a person, so it has no presence and nobody to block.

Field Type Description

ChatLineupPresence

Section titled “ChatLineupPresence”

Object

Field Type Description

presence Presence! ONLINE while anyone hosting as them is in a chat room, PUSH while a notification reaches one of them, else OFFLINE (also for someone nobody has hosted as tonight).

ChatPresenceChanged

Section titled “ChatPresenceChanged”

Object · implements IUserSummary

Someone’s first connection joined the room (ONLINE), or their last one left it or lapsed. Someone who left shows as PUSH to their friends and the room’s admins when a notification still reaches them, otherwise OFFLINE, and stays listed until recentUntil.

Field Type Description
avatarUrl PhotoURL Their profile photo, on arriving.
name String First name and last initial (“Aurora B.”), on arriving; the roster names your friends in full.
presence Presence! Where they are now.
recentUntil ISO8601DateTime On leaving: the room keeps listing them, offline, until then (30 minutes after they were last there, or when what they host there ends).
sharedTribes [Tag!]! The tribes you and they both identify with, for the “You’re both” mark. Only the two of you see it; empty for you and for anyone you share none with.
userId ID! Their user ID.

ChatProvider

Section titled “ChatProvider”

Object · implements IProvider

A chat provider an audience’s rooms can run on (Chat::Provider), and what AudienceKit can do with it: AudienceKit (its own) or Discord. Apps offer only what the provider supports.

Field Type Description
bridges Boolean! Whether a bot can bridge its rooms with the apps’ own (ChatAccount.bridge).
channels Boolean! Whether each venue’s and locale’s room can be one of its channels.
inApp Boolean! Whether the rooms run in the apps (the live room subscriptions and sendMyChatMessage). When false, apps send people to the room’s url instead.
joinTokens Boolean! Whether members join its rooms with a short-lived room token AudienceKit mints once it has checked they may.
key String! Its key, e.g. karafun.
moderates Boolean! Whether the moderation feed sees its rooms.
name String! Its name, e.g. KaraFun.
storesMessages Boolean! Whether AudienceKit holds the rooms’ live state and history itself, rather than the provider carrying them.
verifies Boolean! Whether an account’s credentials can be checked with it.

ChatKind

Section titled “ChatKind”

Enum

What a chat message is. Only messages with a role can be anything but TEXT or REQUEST.

  • ANNOUNCEMENT A title, the message as its body and an optional photo. One per room can be pinned under its title.
  • EVENT One of the audience’s events, with the message as a caption.
  • PHOTO A photo, with the message as a caption.
  • PROMPT One of the event’s chat prompts (prompt), posted as the audience. The newest PINNED one shows under the room’s title.
  • REQUEST A song request or karaoke signup (request), with the message as a note to the host. Anyone in a venue room may send one while the venue takes them (requestSong).
  • SPECIAL A title and body that stop showing at endsAt.
  • TEXT Just what they wrote.

ChatLeftReason

Section titled “ChatLeftReason”

Enum

Why someone is out of a chat room.

  • AWAY They’re no longer at the venue (or in the locale) and tried to speak.
  • BANNED The room’s audience banned them.
  • MOVED They joined another venue’s or locale’s room: a person is in one at a time.
  • REMOVED The venue’s moderators kicked or banned them from its room.

  • STAFF One of the audience’s admins.

ChatSenderKind

Section titled “ChatSenderKind”

Enum

Who a chat message is from (see Sender), as apps draw it. More kinds may come: draw one you don’t know as MEMBER.

  • BOT Software with a name of its own, like Glam, the AI host: its own art with no border or fill, and a bot mark.
  • MEMBER Anyone posting as themself: their own avatar and presence.
  • PERSONA Someone posting as a listing, like a host as their talent page: its name and photo in a ringed circle, with a role badge.
  • SYSTEM The room itself, like a prompt: no avatar, a centred line.
  • VENUE Someone posting as the venue: its name and photo, in a squarer avatar.

Presence

Section titled “Presence”

Enum

Whether someone can be reached right now (see ChatPresence). Only the person themself, their friends and admins see the real value; to anyone else it is always OFFLINE.

  • OFFLINE Neither, or not for this viewer to see.
  • ONLINE Connected to a chat room now.
  • PUSH Not in chat, but signed in on a device that gets push notifications.
