Ticketing

Section titled “Root fields”

TicketingProvider

Section titled “TicketingProvider”

Object · implements IProvider

A ticketing partner events can come from or go to (a Ticketing::Provider), and what it supports.

Field Type Description
accounts Boolean! Whether organizers connect their accounts on it.
key String! Its key, e.g. karafun.
matchesVenues Boolean! Whether its events are read per venue, matched to the partner’s.
name String! Its name, e.g. KaraFun.
publishes Boolean! Whether events created in AudienceKit can be pushed to it.
