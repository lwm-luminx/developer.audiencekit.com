# Listings import schema

JSON Schema (draft 2020-12) for AudienceKit listings import files. Source of truth: lwm-luminx/audience_kit_api
`config/schemas/listings-import/<version>.json`; copy it here when it changes.

- `v1.json`: fixed once published; a breaking change is a new version.
- `latest.json`: the newest version, with its own `$id`.

Usage: /guides/listings-imports/.
