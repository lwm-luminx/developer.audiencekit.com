<CardGrid>
	<Card title="One API, many audiences" icon="puzzle">
		Every audience is a tenant with its own locales, venues, people and events. Scope a GraphQL request to one audience with its endpoint path, and read it as members see it ([GraphQL](/reference/graphql/)) or as staff do ([StaffQL](/reference/staffql/)).
	</Card>
	<Card title="Realtime by default" icon="rocket">
		Chat, presence, the door and every list are GraphQL subscriptions over Action Cable or Server-Sent Events. See [Realtime](/api/realtime/).
	</Card>
	<Card title="Themed per audience" icon="seti:css">
		Each audience picks a preset of the AudienceKit design system, built on [Astryx](https://astryx.atmeta.com/), and may override its accent and spectrum colors. The API checks every override for contrast.
	</Card>
	<Card title="Kept fresh by machines" icon="random">
		Service tokens let workers and AI agents verify venues and events, import listings files and upsert them with provenance.
	</Card>
</CardGrid>
